# Design System

## Palette

| Token | Hex | Role |
|-------|-----|------|
| `--jungle-deep` | `#1A3A2B` | Dark bg, headings |
| `--moss` | `#4E7053` | Secondary text |
| `--sage` | `#8EA98D` | Muted surface, cards |
| `--fern-mist` | `#D5D7C8` | Borders, separators |
| `--warm-cream` | `#FBF7EE` | Main background |
| `--sunlit-gold` | `#F3C46B` | CTA, highlights |
| `--ember` | `#C47A22` | Hover state |

## Typography

| Role | Font | Source |
|------|------|--------|
| Heading | **Instrument Serif** | Google Fonts |
| Body | **Sora** | Google Fonts |

## Visual Approach

- Minimalist jungle — not cartoony. Silhouette leaves, dashed trail paths, low-opacity woodgrain textures.
- Lots of whitespace, limited palette.
- Hub scene: CSS illustration with SVG decorative leaves, dashed paths connecting signposts.
- Mobile hub layout: grid 2-1-2 (2 signposts, avatar, 1 signpost).
- Locked signposts: grayscale. Unlocked: full color + subtle glow.
